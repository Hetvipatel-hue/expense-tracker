# Experiment 10 – Exercise 6 Project Report

**Project:** Expense Tracker  
**Name:** Hetvi Patel  
**Enrollment No.:** 241260131040  
**Subject:** Web Application Development (BE05000281)

## Problem Statement
Manage income and expense records digitally through a full-stack web application.

## Tech Stack
React.js, Axios, React Router, Node.js, Express.js, MongoDB, Mongoose, JWT and Multer.

## Features
Add/Edit/Delete transactions, authentication, protected routes, dashboard summary, search, filtering, sorting, pagination and receipt upload.

## Main APIs
GET /api/ping  
POST /api/auth/register  
POST /api/auth/login  
GET /api/transactions  
POST /api/transactions  
PUT /api/transactions/:id  
DELETE /api/transactions/:id  
POST /api/upload

## Run
Backend:
`cd backend && npm install && npm run dev`

Frontend:
`cd frontend && npm install && npm run dev`

## Result
The project provides a complete React + Express + MongoDB Expense Tracker with JWT authentication and REST API integration.
